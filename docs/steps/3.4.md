## The flow

```
Idle board, no work pick (outside pomodoro blocks):
  free now (outside every block, 06:00–24:00, ≥ 30 min left), no session, deadlines covered?
    yes → "Frei bis 21:00 · Idee aus Später": title, Starte mit, [Jetzt machen] [Meins behalten] [Andere]
            Jetzt machen   → a session with the idea (the board folds away); Done ends the session
            Meins behalten → "Der Rest gehört dir." for this slot (undo: "Doch eine Idee zeigen")
            Andere         → the next idea; none left today → "Der Rest gehört dir." (all had their turn)
    deadline does not fit → the plain "Gerade kein Arbeitsblock" card + "Keine Idee aus Später, solange
                            „Laborbericht“ nicht in deine Arbeitsblöcke passt."
    Later empty           → the plain card, as before
  inside a fixed or pomodoro block, in the night, during a session → no idea
Free time line (time line / Stapel tray / session): "Frei bis 21:00", "Frei ab 21:30", "Ganzer Tag frei",
  "… · gehört dir", with "Meins behalten" whenever the card does not already show it
Ideen (/board/ideas): Later as cards; Jetzt machen, Erledigt (undo); empty state with "Idee erfassen"
```

## Decisions I made (please check)

- **"Jetzt machen" starts a session with the idea**, not "move it into work". It is what the words say, it gets
  the signature moment, and the idea stays in Later until Done. After Done the session ends (no next task from
  To-dos/Tasks), so free time is never filled with work. If unfinished, the normal 25/5 rules apply and
  "Session beenden" is always there.
- **"Deadlines covered" = the load forecast has no crunch**, hard **and** soft. A soft deadline that does not
  fit also stops ideas (it is the same "deadlines safe?" question of the evening loop). Consequence: a user with
  dated tasks but **no pomodoro blocks** never gets ideas (zero capacity); the card says which task is in the way.
- **Free time runs from 06:00 to midnight** and needs **30 minutes** left. No idea at 23:40 or at 02:00.
- **The first look at a free slot records its idea** (one small write on tonight's evening row). This is the only
  read that writes; it is what makes "one idea per slot" and "not twice a day" hold across reloads and devices.
- **"Andere" does not wrap around.** When every Later idea had its turn today, the card says "Alle Ideen aus Später
  waren heute schon dran. Der Rest gehört dir." A Later item added later that day can still come.
- **"Meins behalten" is per slot and undoable** ("Doch eine Idee zeigen"). It also works from inside a block or a
  session: it keeps the **next** free slot today. The preview's mine copy said "Heute kommt keine Idee mehr"; since
  it is per slot, the text says "Bis 21:00 …" / "Heute Abend …" / on a whole free day "Heute …".
- **"Andere" is a quiet third button** (no border) and wraps below the other two on the narrow desktop card; the
  order Jetzt machen · Meins behalten · Andere never changes.
- **Stapel tab "Später" now opens the Ideen page** (was the list sheet). In a session the drawer still opens the
  sheet, so the session stays one tap away. The Werkbank Later column and the Stapel Later sheet link to it ("Als
  Karten").
- **Ideen cards offer only Jetzt machen and Erledigt.** Editing, moving and deleting items do not exist in the new
  shell yet; when they come they belong on these cards too.
- **Size on idea cards only when set** (Later asks no size, so most ideas have none; showing "Short" everywhere
  would be noise).
- **Copy command, not a migration**, for the Bastelideen; done ideas are copied too (as finished), so nothing is lost.
