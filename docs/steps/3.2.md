## The flow

```
first visit from 17:00 (or /board?reset=1)  →  Offer (10:00, Los, Überspringen)
  Los          → Running (countdown, "Schon fertig")  → after 10 min or "Schon fertig" → Battery
  Überspringen → Battery
Battery: Leer / Okay / Voll → board · Später → board (counts as Okay)
"Abschalten" (by hand, any time)  → Running
```

The battery question is skipped when tonight's battery was already answered (the chip counts).

## How it works

| Piece | What |
|---|---|
| `evenings` table | Three new nullable columns: `reset_started_at`, `reset_closed_at`, `battery_asked_at`. Additive; existing rows mean "no reset tonight". A row with a battery already set counts as asked. |
| `App\Services\Planning\EveningReset` | Owns the rules: `stage()` (hidden / offer / running / battery), `remainingSeconds()`, `begin()`, `close()`, `answerBattery()`. A reset that ran its ten minutes is closed by time alone, so reads never write. Two devices closing at once keep the first close. |
| `App\Planning\ResetStage` | The four stages. |
| `Evening::for` / `forWrite` | The race-safe row lookup (risk C14) moved out of `Suggestions` so both services share it. |
| `Suggestions::setBattery` | Also stamps `battery_asked_at`: answering on the chip means tonight's question is done. |
| `Board` | `resetStage` and `resetTimer` computeds; actions `beginReset`, `closeReset`, `answerBattery('low'|'okay'|'good'|'later')`. `?reset=1` is read once in `mount()` into a locked property. |
| `shell/reset.blade.php` | The screen, one for both layouts, fixed over the shell. While it shows, both layout roots are `inert` and `aria-hidden`. Focus goes to Los (offer), "Schon fertig" (running) or Okay (battery). |
| Timer | The existing `sessionTimer` island (app.js), wall-clock based; when it reaches zero it calls `$wire.tick()` and the server moves on to the battery question. |
| `shell/reset-button.blade.php` | "Abschalten" (moon icon), the `reset` action's entry point next to the battery chip: Werkbank top bar and session ribbon with the word, Stapel header in board and session mode as an icon with a label for screen readers. |
| Motion | The screen fades in once (280 ms), the countdown line shrinks with the seconds. Under reduced motion both are instant. The 3.1 fold hooks are untouched. |

## Decisions I made (please check)

- **When is the reset offered without the nudge?** From **17:00 local time** on the first visit of the
  evening (`EveningReset::DUE_FROM`), and at any time when the link `/board?reset=1` is opened. Step 3.3
  replaces 17:00 with your nudge time per weekday, and the nudge's push points at `/board?reset=1`.
  Before 17:00 nothing pops up; "Abschalten" always works.
- **"Überspringen" still asks the battery.** The plan's loop is reset (skippable) → battery (one tap), and
  the battery sizes tonight's suggestion. "Später" is right there if you want neither.
- **Starting by hand goes straight to the countdown**, without the Los screen: you already said you want it.
  It works on paused days and during a session too (it only stops being *offered* there).
- **In a session the pomodoro keeps running** while you reset by hand. The reset does not pause it; say if it
  should.
- **The chip says "Leer" now instead of "Wenig"**, so the same level has one name. (Empty piles also say
  "Leer"; different place, but tell me if it reads oddly.)
- **No streak, no count.** The row only knows whether tonight's reset is open, running or closed. Nothing
  reads it beyond tonight.
