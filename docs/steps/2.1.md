# Step 2.1 · Token layer and the seven themes

Refactor plan step 2.1 (R7, quality bar "themes"; risk C9). Built 2026-11-09 on `feature/theme-tokens`,
stacked on the phase 1 review (PR #13).

## What changed

| Piece | What |
|---|---|
| **Tailwind 4** | Decided by Niels on 2026-11-09. `tailwind.config.js` and PostCSS are gone; Tailwind runs as the `@tailwindcss/vite` plugin and is configured in `resources/css/app.css` (`@theme`). The official upgrade tool renamed classes in 42 old views (`rounded` → `rounded-sm`, `shadow-sm` → `shadow-xs`, `outline-none` → `outline-hidden`, `flex-shrink-0` → `shrink-0`, …). |
| `config/themes.php` | **Single source** for the seven themes: per theme fonts, display weight, two radii, border width, shadow, and 17 colour tokens for light and for dark. |
| `App\Support\Theme` | Reads the user's choice (fallback Topografie / System), renders the theme as `--t-*` variables for the page head, the inline variables for preview cards, and the browser chrome colour. Never throws (error pages still render when the database is down). |
| `App\Support\Contrast` | WCAG contrast ratio and the same `color-mix(in srgb …)` blend the CSS uses for soft tints. |
| `partials/theme-style` | In every page head (app, guest, error and welcome layouts): `<style id="theme-vars">` plus `theme-color` metas. `<html data-mode>` says System / Hell / Dunkel. |
| `app.css` token layer | `@theme inline` maps Tailwind names to the `--t-*` variables. New names: `paper surface line ink ink-soft ink-faint accent accent-fg accent-ink accent-soft good(-soft) warn(-soft) bad(-soft) area-1..3 deep on-deep`, `font-display`, `font-mono`, `rounded-card`, `rounded-panel`, `shadow-card`. The old Topografie names stay as aliases (`forest` → good, `overprint` → area-1, `contour` → warn, `signal` → bad), so **the old screens wear the chosen theme too**. The `dark:` variant follows `data-mode`. |
| Users | Migration `add_theme_to_users_table`: `theme` (default `topografie`) and `color_mode` (default `system`). Additive; every existing user keeps the look they have today. |
| `App\Livewire\ThemePicker` | The "Aussehen" card: seven theme cards (each half shows the theme itself in light and in dark) and System / Hell / Dunkel. Saving dispatches `theme-applied`; `app.js` swaps the head style, so the page repaints without a reload. For now it sits at the top of the old Settings page; the new shell's settings get it in 2.2. |
| Fonts | Self-hosted through Fontsource like before: IBM Plex Mono, Manrope, Bricolage Grotesque, DM Sans, Outfit, Newsreader beside Space Grotesk. Browsers only download the faces the active theme uses. |
| `lang/{de,en}/themes.php` | Card copy and the one-line descriptions. |

## Contrast (REQUIREMENTS § 7)

`ThemeContrastTest` checks every theme in light and dark: ink, soft and faint text on background and card;
ink on the four soft tints; accent text, good, warn and bad on background, card and their own tint; text on
accent buttons; text on the deep colour; the selected chip. All ≥ 4.5:1.

The plan artifact's palettes did not all pass. Only **text** colours moved, by the smallest step that passes;
fills stay as planned:

New token **`accent-ink`**: the accent when it is used as text (eyebrows, links, the active tab). In most
themes it equals the accent; in Kiosk light and Tinte light it is a shade darker.

Area colours are not checked as text on purpose: the new UI shows them only as a dot next to a label in ink.

## Decisions I made (please check)

- **The old screens follow the theme**, through the aliases above. With Topografie (the default) they look as
  before; with another theme they get its colours, fonts and corners. Nobody but you sees another theme
  before the switch, and the old screens go away with the refactor anyway.
- **Light / dark is a per-user setting (System / Hell / Dunkel)**, default System, which is what the old app did.
  Shown as my pick in the phase 2 preview; easy to drop if you prefer "always follow the system".
- **Browser chrome colour = the theme's accent**, as the old app had (green for Topografie).
- **No flame colours in the theme layer.** The streak flame keeps its own colours until the old screens go
  (the refactor has no streaks, CONVENTIONS 11).
